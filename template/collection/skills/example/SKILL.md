# Example skill

Each directory under `skills/` becomes a trackable Beskar skill. The
directory name is the skill name: 1-64 lowercase letters, digits, `-` or `_`.

A skill may contain scripts, references, and any other regular files.
Beskar copies the whole directory and fingerprints its entire content.
